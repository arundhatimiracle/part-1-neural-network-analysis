# Neural Network Analysis

This project focuses on building a neural network model to predict customer churn. The dataset was explored, preprocessed, and used to train a feed-forward neural network.

The project includes:
- Dataset understanding
- Data preprocessing
- Neural network model building
- Training and evaluation
- Hyperparameter experimentation
- Final reflection

Libraries such as TensorFlow, Pandas, NumPy, and Scikit-learn were used during the project.
